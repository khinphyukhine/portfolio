# khin's terminal portfolio 🌸

A cute, terminal-style personal portfolio. Type a command (or tap a chip): `about`, `resume`, `projects`, `fun`, `contact`, `size`, `theme`.

Plain HTML, CSS and JavaScript in one file. No build step.

## Edit the content
Everything lives in the `DATA` block near the top of `index.html`.

## Run locally
Open `index.html` in a browser.

## Visitor stats
Set `goatcounter` in the `DATA` block to your GoatCounter site code. See `index.html`.
